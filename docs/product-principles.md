# Product principles

1. You shouldn't have to know what's important before you log it.
2. Logging imperfectly is better than losing the breadcrumb.
3. It's okay to be sick.

No required explanation, diagnosis, severity, streaks, completion scores, guilt, or automatic inference of improvement. Approximate times must remain visibly approximate. No interpolation across missing symptom observations. Profiles are local containers; one is created automatically. No medication alarms in v1.

Look Back retrieves observations whose recorded instants, uncertainty windows, or explicit durations overlap a selected window. Association is not causation. An unrecorded time period says nothing about how someone felt.

The first milestone is strictly: log → persist/reopen → Timeline → Look Back → JSON backup → restore. Broader medication, episode, customization, and report interfaces come later.
